# Loma Aprende React QA Sandbox

## Inicio rápido
- Opción simple: abrir `index.html` con conexión a Internet.
- Opción recomendada: en esta carpeta ejecutar `python -m http.server 8080` y abrir `http://127.0.0.1:8080`.

## Persistencia
La aplicación utiliza LocalStorage bajo la clave `loma-react-surveys-v1`. Los datos persisten al recargar, pero solo en el navegador y origen utilizados.

## Tutorial
Dentro de la aplicación, pulse **Tutorial**. También se incluye `TUTORIAL.md`.

## Nota
React se carga desde CDN para que el proyecto sea estático y no requiera npm. No existe backend ni conexión a Power Apps.
